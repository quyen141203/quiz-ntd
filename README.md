# QuizNTD v3

Bản này thêm giao diện tài khoản Giáo viên/Học sinh, dashboard, tạo bài, mã/link chia sẻ, học sinh chỉ cần nhập tên, và giáo viên xem kết quả.

## Quan trọng
Bản này chạy DEMO bằng localStorage nên dữ liệu chỉ nằm trên cùng trình duyệt/máy. Muốn giáo viên theo dõi học sinh trên nhiều thiết bị theo thời gian thực, cần backend như Firebase/Supabase. Giao diện đã được thiết kế để nâng cấp phần đó.

## Deploy GitHub Pages
Upload `index.html` lên repository GitHub Pages giống bản trước.
